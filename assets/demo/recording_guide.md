# RepoMind AI Recording Guide

Use this guide to record a polished portfolio demo for GitHub, LinkedIn, resume links, and internship applications.

## Recording Settings

| Setting | Recommendation |
| --- | --- |
| Resolution | 1920x1080 |
| Frame rate | 30 FPS |
| Theme | Dark |
| Browser | Chrome |
| Browser zoom | 100% |
| Sidebar | Visible |
| Bookmarks bar | Hidden |
| Extensions | Hidden |
| Desktop notifications | Off |
| Terminal windows | Hidden |
| Cursor motion | Slow and deliberate |
| Audio | Clear microphone, quiet room |

## Browser Preparation

1. Open Chrome with a clean browser profile.
2. Hide the bookmarks bar.
3. Disable or hide extension icons.
4. Set zoom to 100%.
5. Open RepoMind AI at `http://localhost:8501`.
6. Confirm dark theme is active.
7. Use a repository that is already indexed so no loading delays appear.

## Capture Flow

1. Start on Repository Intelligence.
2. Show repository selection and overview cards.
3. Scroll to Ask Repository.
4. Enter `Explain the repository architecture`.
5. Show Fast Mode, then briefly show Deep Analysis.
6. Show generated report formatting.
7. Show evidence and citations.
8. Show Module Explorer.
9. Show Repository Health.
10. Show Retrieval Evaluation.
11. Show export report options.

## Editing Notes

- Keep the final video between 2 and 3 minutes.
- Cut out loading delays and repeated clicks.
- Avoid zooming too aggressively; text should remain readable.
- Keep transitions simple.
- Export at 1080p, 30 FPS.
- Use the README GIF as a short preview, and link the full demo video separately.
