# RepoMind AI Demo Checklist

## Before Recording

- [ ] App opens at `http://localhost:8501`.
- [ ] Dark theme is active.
- [ ] Browser zoom is 100%.
- [ ] Sidebar is visible.
- [ ] Bookmarks and extensions are hidden.
- [ ] Sample repository is indexed.
- [ ] No terminal windows or debug output are visible.
- [ ] No loading spinners are present in the final captured moments.

## README GIF

- [ ] Shows RepoMind AI opening.
- [ ] Shows repository selection or dashboard.
- [ ] Shows the question: `Explain the repository architecture`.
- [ ] Shows a generated grounded answer.
- [ ] Shows visible evidence or citations.
- [ ] Loops smoothly.
- [ ] Duration is between 15 and 25 seconds.

- [ ] Introduction explains what RepoMind AI is.

## Final Review

- [ ] Audio is clear.
- [ ] Text is readable.
